Fit to window

  1. Set the projector's own keystone and zoom to neutral, aim it at the window, then press Show pattern.
  2. Take a photo from where people will watch, with the whole pattern and the window in view.
  3. Load the photo. Click the projected corners 1, 2, 3, 4 (the coloured numbers), then the window's corners: top-left, top-right, bottom-right, bottom-left.
  4. Fine-tune by dragging the corners below (or select one and use the arrows). While the pattern is on, the projector shows the shape in orange.
  5. Press Done. Clips now play inside the shape with black around it.

Groups

A group is a set of projectors that share a schedule and take commands together, like the garage doors or the upstairs windows.

Schedules

A schedule says what plays when. Save it once, then pick it on any projector. Projectors keep following their schedule when the Pi or Wi-Fi is down.

Updates

The Pi checks GitHub for new SceneSync releases. Projectors get the player app from the Pi, all at once.
